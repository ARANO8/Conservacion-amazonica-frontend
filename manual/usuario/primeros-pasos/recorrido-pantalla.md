# Recorrido de la pantalla

Después de ingresar, la pantalla tiene dos partes: el **panel lateral** a la izquierda, con el
menú, y el **área de trabajo** a la derecha, donde se abre cada página.

![Pantalla de Inicio con el panel lateral desplegado](/img/capturas/inicio-panel.png)

## Barra superior

- El botón con el ícono de panel, arriba a la izquierda, **oculta o muestra el panel lateral**.
  El sistema recuerda tu preferencia.
- A su lado, la **ruta de navegación** indica en qué página estás (por ejemplo, Compras y
  Servicios, luego Cuadros Comparativos, luego el detalle). Cada tramo es un enlace para
  volver atrás. En pantallas pequeñas no se muestra.

## El panel lateral

Arriba está el logo de AMZ Desk y el botón de tema (claro u oscuro). Debajo, el menú principal.
Lo que aparece depende de tu rol: ver [Roles y qué ve cada uno](./roles.md).

| Entrada                 | Qué contiene                                                                                                                                   |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **Inicio**              | Página de bienvenida, accesos rápidos y el **Dashboard de Métricas**                                                                           |
| **Viajes y Viáticos**   | **Planes de Viaje**, **Mis Solicitudes**, **Mis Rendiciones**, **Informe de Viaje**, **Liquidación de Viáticos**, **Declaración de Movilidad** |
| **Compras y Servicios** | **Solicitudes de Fondos**, **Mis Cotizaciones**, **Cuadros Comparativos**, **Órdenes de Compra**                                               |
| **Notificaciones**      | La **Bandeja de Entrada**: avisos y trámites que esperan tu acción. Ver [Notificaciones](./notificaciones.md)                                  |
| **Centro de Auditoria** | Trazabilidad de solicitudes y rendiciones (solo algunos roles)                                                                                 |
| **Gestion de Usuarios** | Alta y edición de cuentas (solo administración)                                                                                                |
| **Base Documental**     | Manuales, instructivos y formularios en blanco. Ver [Base Documental](./base-documental.md)                                                    |
| **Monitores**           | **Solicitudes** y **Rendiciones**: vista global de solo lectura (solo algunos roles)                                                           |
| **Analítica**           | Tendencias y distribución presupuestaria (solo algunos roles)                                                                                  |

Las entradas con flecha (**Viajes y Viáticos**, **Compras y Servicios**, **Monitores**) se
despliegan al pulsarlas.

### Navegación secundaria

Al pie del menú, separadas del resto:

- **Manual de usuario**: abre este manual en una pestaña nueva.
- **Manual técnico**: documentación para quien mantiene el sistema. Se abre en una pestaña nueva.
- **Soporte**: abre una ventana con la dirección de correo de soporte, el asunto sugerido
  (`[AMZdesk] Soporte tecnico`) y qué datos incluir: el módulo o pantalla, qué hiciste, qué
  esperabas, qué obtuviste y la fecha y hora aproximada. El botón **Enviar Correo** abre tu
  programa de correo con el mensaje ya armado.
- **Feedback**: igual que Soporte, pero para sugerencias de mejora (asunto
  `[AMZdesk] Sugerencia de mejora`).

### Tu cuenta

En la parte inferior del panel aparece tu nombre y correo. Al pulsarlo se abre un menú con:

- **Notificaciones Recientes**: las tres últimas sin leer, con un contador rojo.
- **Ver todas las notificaciones**: abre la Bandeja de Entrada.
- **Cuenta**: el rol con el que estás trabajando (por ejemplo `USUARIO` o `CONTADOR`).
- **Cerrar Sesion**.

## La página de Inicio

La página **Inicio** muestra el saludo **Bienvenidos AMZ desk** y, debajo, accesos rápidos que
cambian según tu papel:

- Si revisas o apruebas (roles de administración, o si alguien te asignó una solicitud), ves la
  tarjeta **Revisión de Solicitudes** con el botón **Ir a Revisión**, que abre la Bandeja de
  Entrada.
- Si no, ves **Nueva Solicitud de Fondos** (botón **Crear solicitud**, que abre la solicitud de
  viaje) y **Rendición de Fondos** (botón **Cargar rendición**).

Más abajo está el **Dashboard de Métricas**: las tarjetas **Solicitudes Activas**,
**Rendiciones Pendientes** y **Monto por Rendir**, la lista **Últimas Solicitudes** y, solo
para `ADMIN`, `EJECUTIVO` y `TESORERO`, el termómetro **Salud Financiera del POA Global**.

:::tip Modo oscuro
El botón de tema está arriba del panel lateral y también en la pantalla de ingreso. Los
documentos (anexos) siempre se ven como papel blanco, aunque uses el modo oscuro.
:::
