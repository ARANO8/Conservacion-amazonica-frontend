# Base Documental

La **Base Documental** reúne los documentos institucionales de referencia para el personal de
ACEAA. Todos los roles la ven en el panel lateral.

## Qué contiene

| Documento                                | Categoría      |
| ---------------------------------------- | -------------- |
| Instructivo de Manejo de Fondos          | Financiero     |
| Manual de Procedimientos Administrativos | Administrativo |
| Plan Operativo Anual 2026                | Planificación  |
| Planilla de Alimentación                 | Financiero     |
| Planilla de Viáticos para Terceros       | Financiero     |
| Planilla de Pasajes para Terceros        | Financiero     |

Las tres planillas son los formularios en blanco de los anexos 8, 8A y 9: se descargan, se
llenan y firman a mano, y el escaneo se adjunta en la rendición como `PAT`, `PVT` o `PPT`.

Cada tarjeta tiene, según el documento:

- **Ver** y el botón de descarga, para los archivos guardados en el sistema.
- **Abrir**, para los enlaces externos (hoy, el Plan Operativo Anual, que abre una planilla
  compartida).

## Agregar o actualizar documentos

La lista es fija: no hay pantalla para subir documentos, tampoco para `ADMIN`. Para incorporar
o reemplazar un documento, pídelo al equipo técnico. La propia pantalla lo indica: "Para
solicitar la incorporación de nuevos documentos, contacta al administrador del sistema".
