# Manual de usuario de AMZ Desk

AMZ Desk es el sistema de ACEAA para pedir, aprobar, desembolsar y rendir fondos: los viajes
con sus viáticos y las compras de bienes y servicios. Reemplaza las planillas en papel por
formularios que siguen un flujo de aprobación y que generan los anexos oficiales listos para
imprimir y firmar.

## Por dónde empezar

| Si eres...                                                                     | Lee primero                         |
| ------------------------------------------------------------------------------ | ----------------------------------- |
| Nuevo en el sistema                                                            | [Primeros pasos](./primeros-pasos/) |
| Personal que viaja                                                             | [Viajes y viáticos](./viajes/)      |
| Quien pide una compra o un servicio                                            | [Compras y servicios](./compras/)   |
| Director de Programa, Dirección Financiera, Contabilidad o Dirección Ejecutiva | [Guías por rol](./roles/)           |
| Administrador del sistema                                                      | [Administración](./administracion/) |

¿Dudas sobre un estado, un impuesto o una palabra? Revisa la [Referencia](./referencia/).

## Los documentos que genera

Cada paso produce su anexo, con el logo de ACEAA a la izquierda, el de AMZ Desk a la derecha
y, en cada firma, el nombre y el cargo de quien firma.

| Documento                                        | Para qué sirve                                  |
| ------------------------------------------------ | ----------------------------------------------- |
| ANEXO 1 — Planificación de Viaje                 | Planificar el viaje antes de pedir fondos       |
| ANEXO 2 — Solicitud de Fondos para Viajes        | Pedir los fondos del viaje                      |
| ANEXO 4 — Rendición de cuentas                   | Justificar en qué se gastaron los fondos        |
| ANEXO 5 — Liquidación de Viáticos                | Liquidar los viáticos de cada persona del viaje |
| ANEXO 6 — Declaración Jurada de Movilidad        | Declarar los traslados sin factura              |
| ANEXO 7 — Informe de Viaje                       | Informar qué se hizo en el viaje                |
| Cotización, cuadro comparativo y orden de compra | Comprar bienes y servicios                      |

:::tip Busca en el manual
Usa el buscador de arriba a la derecha: escribe, por ejemplo, "observado" o "liquidación".
:::

¿No encuentras lo que buscas? Usa **Soporte** en el panel lateral de AMZ Desk.
