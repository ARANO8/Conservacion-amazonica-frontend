# Glosario

Términos que usa AMZ Desk, en orden alfabético. Las palabras del dominio se dejan en español,
tal como las usa ACEAA.

| Término                             | Significado                                                                                                                          |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **ACEAA**                           | Asociación de Conservación Amazónica, la organización dueña de AMZ Desk                                                              |
| **Actividad**                       | Cada fila del plan de viaje: qué se hace, dónde, cuándo y con cuántas personas. También, la descripción de una línea del POA         |
| **ADMIN**                           | Rol que administra el sistema: gestiona usuarios y ve todo                                                                           |
| **Anexo**                           | Cada formulario oficial del Manual de Procedimientos Administrativos. AMZ Desk genera los anexos 1, 2, 3, 4, 5, 6, 7, 11 y 12 en PDF |
| **ANEXO 1**                         | Plan de Viaje (Planificación de Viaje)                                                                                               |
| **ANEXO 2**                         | Solicitud de Fondos para Viajes                                                                                                      |
| **ANEXO 3**                         | Solicitud de Fondos en Avance para compras y servicios                                                                               |
| **ANEXO 4**                         | Rendición de Fondos en Avance                                                                                                        |
| **ANEXO 5**                         | Liquidación de Viáticos, una hoja por persona                                                                                        |
| **ANEXO 6**                         | Declaración Jurada de Movilidad                                                                                                      |
| **ANEXO 7**                         | Informe de Viaje                                                                                                                     |
| **ANEXO 8 / 8A / 9**                | Planillas de alimentación, viáticos y pasajes de terceros. Se descargan en blanco de la Base Documental                              |
| **ANEXO 11**                        | Cuadro Comparativo de Cotizaciones                                                                                                   |
| **ANEXO 12**                        | Orden de Compra o de Servicio                                                                                                        |
| **Aprobador**                       | La persona que tiene un documento en su bandeja y debe decidir sobre él                                                              |
| **Base Documental**                 | Pantalla con los manuales, instructivos y formularios de referencia                                                                  |
| **Bandeja de Entrada**              | La pantalla de **Notificaciones**: todo lo que te llega para revisar o te avisa de un cambio                                         |
| **Boleta**                          | Comprobante sin valor de factura. En la rendición retiene como un recibo                                                             |
| **Bruto**                           | Lo que un gasto le cuesta a ACEAA, impuestos incluidos. Es lo que se descuenta del POA. También "presupuestado"                      |
| **Código de desembolso**            | El número de la transferencia o comprobante que registra Dirección Financiera al desembolsar                                         |
| **Código POA**                      | Identificador de una línea del POA                                                                                                   |
| **Código presupuestario**           | El código completo de una línea presupuestaria                                                                                       |
| **Comprometido**                    | Monto reservado en el POA por solicitudes en curso (`PENDIENTE`, `DESEMBOLSADO`, `EN_EJECUCION`)                                     |
| **Comprobante**                     | El respaldo de un gasto o de un desembolso. En AMZ Desk es siempre un **enlace** (Google Drive, OneDrive…), no un archivo subido     |
| **Concepto**                        | Tarifa diaria de viático según el destino, con un monto para personal institucional y otro para terceros                             |
| **CONTADOR**                        | Rol de Contabilidad: cierra las rendiciones y revisa los cuadros comparativos                                                        |
| **Contrato de consultoría**         | Solicitud de compra o servicio que se paga por cuotas. Nace en `EN_EJECUCION`                                                        |
| **Cotización**                      | Presupuesto de un proveedor. Puede ser **propia** (cargada ítem por ítem) o **externa** (el documento del proveedor, enlazado)       |
| **Cotización recomendada**          | La que el cuadro comparativo propone elegir; de ella se precarga la orden de compra                                                  |
| **Cronograma de Pagos**             | Las cuotas de un contrato de consultoría, con su monto, fecha y estado                                                               |
| **Cuadro comparativo**              | Tabla que compara las cotizaciones de una compra (ANEXO 11). Pasa por Contabilidad, el Validador de compras y Dirección Ejecutiva    |
| **Cuenta bancaria**                 | Cuenta de ACEAA asociada a un proyecto                                                                                               |
| **Cuota**                           | Cada pago parcial de un contrato de consultoría                                                                                      |
| **Declaración Jurada de Movilidad** | Documento para declarar traslados sin factura (ANEXO 6)                                                                              |
| **Derivar**                         | Pasar un documento a la siguiente persona que debe revisarlo, sin cambiar su estado                                                  |
| **Desembolsar / desembolso**        | Entregar los fondos de una solicitud. Lo hace Dirección Financiera                                                                   |
| **Dirección Ejecutiva**             | Rol `EJECUTIVO`. Aprueba los cuadros comparativos; el Director Ejecutivo firma en papel el ANEXO 1 y los demás anexos                |
| **Dirección Financiera**            | Rol `TESORERO`. Aprueba y desembolsa las solicitudes                                                                                 |
| **Director de Programa**            | La persona que el emisor elige para revisar su solicitud de viaje, su informe o su liquidación. No es un rol del sistema             |
| **Disponible**                      | Lo que queda de una línea del POA: costo total menos ejecutado menos comprometido                                                    |
| **DJ**                              | Tipo de documento "Declaración Jurada" en la rendición. No retiene                                                                   |
| **EJECUTIVO**                       | Rol de Dirección Ejecutiva                                                                                                           |
| **Ejecutado**                       | Monto que ya se gastó y se rindió contra una línea del POA                                                                           |
| **Emisor**                          | Quien crea un documento. En la gestión de usuarios, el rol `USUARIO` se muestra como **EMISOR**                                      |
| **Estructura programática**         | La combinación proyecto, grupo y partida de la que cuelga cada línea del POA                                                         |
| **Factor**                          | El número por el que se divide el líquido para obtener el bruto (0,87, 0,84, 0,92 o 1,00)                                            |
| **Factura**                         | Comprobante fiscal del proveedor. No genera retención                                                                                |
| **Gasto**                           | Cada línea de dinero de una solicitud o de una rendición                                                                             |
| **Grupo**                           | Segundo nivel del presupuesto, dentro de un proyecto                                                                                 |
| **Hoja de liquidación**             | La parte de la Liquidación de Viáticos de una persona                                                                                |
| **Hospedaje**                       | Alojamiento dentro de una solicitud de viaje; su monto por noche está acotado según la región                                        |
| **Informe de Viaje**                | Lo que se hizo realmente en el viaje (ANEXO 7). Lo revisa el Director de Programa                                                    |
| **Institucional (personal)**        | Personal de ACEAA que viaja. Se elige entre los usuarios del sistema                                                                 |
| **IT**                              | Impuesto a las Transacciones, 3 %                                                                                                    |
| **IUE**                             | Impuesto sobre las Utilidades de las Empresas, 5 % en compras de bienes con recibo                                                   |
| **IVA**                             | Impuesto al Valor Agregado, 13 %                                                                                                     |
| **Línea del POA**                   | Cada ítem presupuestado del POA, con su código, actividad y costo total                                                              |
| **Liquidación de Viáticos**         | Cálculo final de los viáticos de cada persona después del viaje (ANEXO 5)                                                            |
| **Líquido**                         | Lo que la persona recibe en la mano, después de retenciones. También "neto"                                                          |
| **LV**                              | Tipo de documento "Liquidación de Viáticos" en la rendición. Retiene RC-IVA 13 %                                                     |
| **Medio viático**                   | 50 % de la tarifa diaria, cuando la jornada no se completa o la alimentación está cubierta                                           |
| **Nómina de terceros**              | La lista de personas externas que participan en las actividades de un viaje                                                          |
| **Observar**                        | Devolver un documento a su autor con un motivo para que lo corrija. No es un rechazo                                                 |
| **Orden de compra**                 | Documento que se emite al proveedor elegido (ANEXO 12)                                                                               |
| **PAT**                             | Planilla de Alimentación de Terceros (ANEXO 8). Retiene 16 %                                                                         |
| **Partida**                         | Línea presupuestaria. Tercer nivel del presupuesto, dentro de un grupo                                                               |
| **Partida contable**                | Cuenta del plan de cuentas contable con la que se clasifica cada gasto de la rendición                                               |
| **Plan de Viaje**                   | Planificación previa de todo viaje (ANEXO 1). Sin aprobación en el sistema                                                           |
| **POA**                             | Plan Operativo Anual: el presupuesto anual de ACEAA                                                                                  |
| **PPT**                             | Planilla de Pasajes de Terceros (ANEXO 9). No retiene                                                                                |
| **Proyecto**                        | Primer nivel del presupuesto; cada uno tiene su cuenta bancaria                                                                      |
| **PVT**                             | Planilla de Viáticos de Terceros (ANEXO 8A). Retiene RC-IVA 13 %                                                                     |
| **RC-IVA**                          | Régimen Complementario al IVA, 13 %. Es la retención de los viáticos                                                                 |
| **Recibo**                          | Comprobante sin factura. Obliga a ACEAA a retener impuestos                                                                          |
| **Rendición**                       | Justificación de los fondos desembolsados, con sus comprobantes (ANEXO 4)                                                            |
| **Retención**                       | Impuesto que ACEAA descuenta y paga en nombre de quien no entrega factura                                                            |
| **Revisar**                         | En el Informe de Viaje y la Liquidación de Viáticos, la aprobación del Director de Programa                                          |
| **Saldo**                           | En la rendición, la diferencia entre lo recibido y lo gastado: a devolver o a reembolsar                                             |
| **Sede**                            | Oficina de la persona: La Paz, Trinidad o Cobija. Propone el lugar de emisión del ANEXO 1                                            |
| **Solicitud**                       | Pedido de fondos para un viaje (`VIAJE`) o para una compra o servicio (`COMPRA_SERVICIO`)                                            |
| **TESORERO**                        | Rol de Dirección Financiera                                                                                                          |
| **Terceros**                        | Personas externas a ACEAA que participan en una actividad: comunarios, autoridades, técnicos                                         |
| **Tipo de gasto**                   | Compra, Alquiler, Servicio, Peaje o AutoCompra. Con recibo, define la retención                                                      |
| **USUARIO**                         | Rol del personal que pide fondos. Se muestra como **EMISOR**                                                                         |
| **VALIDADOR_COMPRAS**               | Rol del Validador de compras (Adquisiciones). Valida los cuadros comparativos                                                        |
| **Viático**                         | Asignación diaria para gastos de viaje, según la tarifa del destino                                                                  |
| **VoBo**                            | Visto bueno. El del ANEXO 1 lo firma en papel el Director Ejecutivo                                                                  |
